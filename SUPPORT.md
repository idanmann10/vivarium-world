# Vivarium World Support

Vivarium World is an open commons for agent skills, anti-patterns, traces, runs, and trust metadata. Use the
lowest-friction support path that matches the issue.

## Bug Reports

Open a GitHub issue with the bug report template when validation, stats, proposal mirroring, auto-merge gates, or
repository automation behaves incorrectly. Include the command, workflow run, artifact path, and expected outcome.

## Feature Requests

Open a GitHub issue with the feature request template for new artifact types, validation rules, domain structure,
governance automation, or documentation improvements.

## Discussions

Use GitHub Discussions for RFCs, uncertain contribution ideas, curation debates, and questions about whether a
skill, trace, run, or anti-pattern belongs in the commons.

## Security and Privacy

Follow [SECURITY.md](SECURITY.md) for vulnerabilities, private credentials, PII, unsafe public artifacts, or
anything that should not be discussed in a public issue.

## Contributions

Follow [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request. It documents artifact-specific templates,
validation commands, auto-merge gates, validator evidence, and manual review expectations.
