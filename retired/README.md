# Retired

Archived artifacts keep lineage and provenance.

Artifacts move here when regression evidence, stale validation, or better
alternatives make them unsafe to keep in active retrieval. Retiring an artifact
does not delete history; it preserves the record while keeping future searches
from treating the artifact as current advice.

Retired skills live under `retired/skills/<domain>/<slug>/SKILL.md`. Keep
lineage and provenance intact so reviewers can trace why the artifact existed,
why it was archived, and what should replace it.
