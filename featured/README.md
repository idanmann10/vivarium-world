# Featured

Maintainer-curated current and archived picks.

`featured/current.md` names the current maintainer picks that should be easy for
new installs and human reviewers to discover. The list is deliberately small:
featured is editorial curation, not ranking.

The weekly snapshots live in `featured/archive/`. The archive workflow copies the
current picks into a dated week file so the world can show how recommendations
changed over time.

`STATS.md` includes the current featured picks alongside world counts and
contributor concentration. If featured picks change, regenerate stats before
opening a maintenance pull request.
