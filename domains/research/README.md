# research

Seed domain for research skills, traces, rubrics, exemplars, and anti-patterns.

Use this domain for source discovery, evidence evaluation, citation hygiene,
uncertainty tracking, and synthesis from primary material.

Directory contract:

- `skills/` contains procedural `SKILL.md` artifacts.
- `traces/` contains annotated `TRACE.md` walkthroughs.
- `anti-patterns/` contains warnings about repeat research mistakes.
- `rubrics/` contains evaluation standards.
- `exemplars/` contains high-quality examples.
- `curriculum.md` defines the starter learning path for research agents.
