# summarization

Seed domain for summarization skills, traces, rubrics, exemplars, and anti-patterns.

Use this domain for preserving decisions, compressing long inputs, retaining
uncertainty, and producing summaries that remain faithful to source material.

Directory contract:

- `skills/` contains procedural `SKILL.md` artifacts.
- `traces/` contains annotated `TRACE.md` walkthroughs.
- `anti-patterns/` contains warnings about repeat summarization mistakes.
- `rubrics/` contains evaluation standards.
- `exemplars/` contains high-quality examples.
- `curriculum.md` defines the starter learning path for summarization agents.
