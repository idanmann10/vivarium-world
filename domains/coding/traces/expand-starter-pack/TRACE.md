# Goal

Expand a coding starter pack without weakening validation.

## Step 1 - Add the failing count test

Write the test that describes the v1 starter-pack depth before adding content.

## Step 2 - Add only missing content

Add enough skills and traces to meet the range, keeping the content focused and public.

## Step 3 - Re-run world gates

Run the world validator, typecheck, tests, and build before committing.

## Common pitfalls

Adding content without updating stats or without making the retrieval query able to find it.

## Alternatives

If content quality is uncertain, add fewer artifacts and keep the failing count visible.
