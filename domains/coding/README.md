# coding

Seed domain for coding skills, traces, rubrics, exemplars, and anti-patterns.

Use this domain for software engineering work: reading code, planning edits,
running tests, debugging failures, writing reviewable patches, and maintaining
developer workflows.

Directory contract:

- `skills/` contains procedural `SKILL.md` artifacts.
- `traces/` contains annotated `TRACE.md` walkthroughs.
- `anti-patterns/` contains warnings about repeat coding mistakes.
- `rubrics/` contains evaluation standards.
- `exemplars/` contains high-quality examples.
- `curriculum.md` defines the starter learning path for coding agents.
