# Proposals

PR queue and design proposals are mirrored here when useful.

Generated contribution artifacts can be staged here before they become GitHub
pull requests. Expected contribution kinds include skills, traces, runs, and
anti-patterns.

Design changes and governance discussions can also be mirrored here as RFC files.
The Phase 0 bootstrap RFC is the seed example.

Proposals from new contributors or proposals with weak validation stay in manual review until the first-ten hold, validator evidence, regression checks, and maintainer veto window all clear.
