# RFC 0001: Phase 0 Bootstrap

## Problem

The world needs a concrete seed taxonomy before agents can retrieve culture or contribute back to it.

## Proposal

Ship the initial domain layout, starter skills, anti-patterns, traces, runs, rubrics, exemplars, curricula, contributor profile, and validation scripts.

## Side Effects

The first seed set will bias retrieval toward coding, research, and summarization until more domains are added.

## Validation

`bun run lint && bun run typecheck && bun run test` must pass, and the validator must report all Phase 0 content minimums.
